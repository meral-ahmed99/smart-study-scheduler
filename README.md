# Smart Study Scheduler

A web app that builds a day-by-day study schedule from your tasks and deadlines.

## Features
- Add up to 3 tasks at once (name, subject, due date, hours needed)
- Colour-coded task list with days left
- Builds a daily schedule based on your free hours
- Shows start, finish and deadline for each task
- Warns you if a deadline cannot be met

## Built with
HTML, CSS and JavaScript

## How to run
Download all three files (index.html, style.css, script.js) into one folder and open index.html in Chrome.
